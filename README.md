# Tangram-Werkstatt

Digitales Tangram für den Mathematikunterricht der Grundschule (Klasse 1–4) und für die Lehrerbildung.

**App öffnen:** https://docschwob.github.io/tangram-werkstatt/

- Schwierigkeitsleiter in sechs Stufen: farbig vorgezeichnet · Innenlinien · Umriss · Umriss verkleinert · nur in Worten · selbst erfinden
- Teile frei drehen und spiegeln, Einrasten an Ecken zuschaltbar
- Prüfen nur auf Anfrage, auf Wunsch mit Markierung von Lücken, Überständen und Überlappungen
- Hilfen, Rückgängig, Schrittprotokoll mit Wiedergabe, Präsentationsmodus
- Läuft im Browser auf Tablet und Rechner, ohne Anmeldung und ohne Installation
